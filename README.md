## 📖 About the Project

**NutriWell** is a static front-end website designed to make nutrition information simple, practical, and accessible. It was built as a **Web Technologies** front-end assignment, with a strong emphasis on clean UI design, full responsiveness, and real JavaScript interactivity — no frameworks, no backend, just solid fundamentals.

The site walks a visitor through healthy-living content across five interconnected pages: a landing page, an about section, a nutrition hub with tools, a recipe library, and a contact page featuring a real nutrition expert.

---

## 📄 Pages Overview

| # | Page | File | What it does |
|---|------|------|---------------|
| 1 | 🏠 Home | `index.html` | Landing page — quick access to all sections |
| 2 | ℹ️ About | `about.html` | NutriWell's mission and core nutrition principles |
| 3 | 🥗 Nutrition | `nutrition.html` | Food explorer, BMI calculator, nutrition categories |
| 4 | 🍳 Recipes | `recipes.html` | Recipes filtered by breakfast, lunch, dinner, snacks, salads, desserts & smoothies |
| 5 | 📩 Contact | `contact.html` | Contact form + featured nutrition expert profile |

## ✨ Features

- 🌗 **Dark Mode Toggle** — smooth light/dark theme switching
- 📱 **Mobile Hamburger Menu** — responsive navigation for small screens
- 🔍 **Interactive Food Explorer** — filter foods by category
- 🍽️ **Recipe Filtering System** — browse recipes by type
- 🪟 **Recipe Detail Modal** — clean popup view for full recipe info
- ⚖️ **BMI Calculator** — validated inputs, instant results
- ✅ **Form Validation** — contact form & newsletter signup
- 💡 **Daily Nutrition Tips** — dynamic, changing content
- 👩‍⚕️ **Nutrition Expert Section** — featured dietitian profile

- 🎨 **Fully Responsive Layout** — desktop, tablet & mobile

## 🚀 Getting Started

No build tools, dependencies, or backend needed.

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/NutriWell.git

# 2. Move into the project folder
cd NutriWell

# 3. Open index.html in your browser
```

> 💡 Tip: Use the **Live Server** extension in VS Code for the smoothest experience with auto-reload.
